FLUENTSTEP PRO - ANDROID PWA
1. Extract this ZIP.
2. Upload every file and the icons folder to the ROOT of a GitHub repository (keep folder structure).
3. In GitHub: Settings -> Pages -> Deploy from a branch -> main -> /(root) -> Save.
4. Wait for GitHub Pages to publish. Open the published HTTPS URL in Chrome on Android.
5. Chrome menu (three dots) -> Install app / Add to Home screen. If Install app is available, choose it.
6. Open FluentStep from the home screen. It works offline after the first successful load.

IMPORTANT DATA NOTES
- Your vocabulary and records are stored locally in this browser on this phone.
- Export the full JSON backup regularly and keep a copy somewhere safe.
- Clearing Chrome site data, changing browser, or resetting the phone can remove local records.
- JSON restore replaces the records currently stored in the app.
- CSV export contains vocabulary only.
- This is a Progressive Web App, not an APK from the Play Store.
- Browser-based reminders are limited. Exact alarms/notifications while the app is fully closed are not guaranteed.
